# UI Guidelines

## No Status Cards / Badges with Dots
- **Strict Rule**: Do NOT add status pills, telemetry badges, or cards containing pulsing/blinking dots (such as green/red radar dots, "STATUS: ACTIVE", "FLIGHT BSK-...", live indicator dots, etc.) in any section of the website (Hero, Footer, About, Channels, etc.).
- Keep headers, footers, and section headers clean, modern, and uncluttered without simulated status telemetry widgets or pulsing dots.
